Simplest beginner flow:
Install Expo Go on your Android phone
Run:
npm.cmd run dev:mobile
Make sure the terminal says Using Expo Go
Scan the QR code from Expo Go
Wait for the app to bundle and open
Useful controls while it runs:
r reloads the app
w opens web preview in browser
Ctrl + C stops the frontend server
s switches between Expo Go and development build
For you, stay on Expo Go. Do not switch to development build right now.
